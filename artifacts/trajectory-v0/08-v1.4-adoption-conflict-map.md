## Q12 — which files must a Trajectory branch not touch?

**`PARTIAL`,** and the partiality is honest rather than incidental: the constraint set is *committed*
for Workstream M and *inferred* for the four stable schemas.

### Committed, verbatim

[artifacts/mcp-2026-07-28/non-goals.md](../../artifacts/mcp-2026-07-28/non-goals.md) enumerates the
forbidden paths for Workstream M, and its rows apply equally to T because the reasons are not
M-specific:

| Forbidden | Its committed reason |
| --- | --- |
| Moving any verdict | *"`computeVerdict` is the sole adjudicator and is a forbidden path for Workstream M"* |
| The 13-tool / 19-resource counts | *"Frozen surface"* |
| Adding a runtime dependency to the MCP package | `dependencies` stays `{}`, *"gated at `mcp-pack-smoke.mjs:67-69"`* |
| Executing / importing / starting / connecting to / authenticating against a target | *"Forbidden for both M and T"* — stated for both explicitly |
| `PROTOCOL_VERSION` | Stays `2024-11-05`; claiming 2026-07-28 before F1–F8 is on the forbidden-copy list |

The fourth row is the only one that names T directly, and it is the strongest: no execution, no
import, no connection, no authentication against any target. A trajectory feature that observed
real agent runs would have to do so through Host-emitted events only — which is precisely why
[04](04-host-evidence-capability-matrix.md)'s matrix is the binding constraint on the whole idea.

### Inferred, and labelled as inference

`docs/new16-new17-integration.md:404` refers to *"the four stable schemas"* **by category name
only**. No committed file enumerates them, and `pnpm schema:compat` covers all **30**
([02](02-schema-and-type-map.md)). The four inferred from the digest chain are:

```
decision.schema.json          — the TrustDecision document
decision-receipt.schema.json  — the receipt, incl. `supersedes`
authority-manifest.schema.json — object 3, what a decision decides over
artifact-identity.schema.json — object 1, what was pinned
```

**This is an inference, not a measurement.** It is recorded as one because writing an inference as a
measurement is the failure this audit format exists to prevent. What *is* measured: all four are
closed (`additionalProperties: false`) and all four are covered by the rejection gate, so a
trajectory field added to any of them reds CI regardless of whether the "stable four" label is
correct.

### The `docs/` constraint

`.gitignore:44` is `docs/`, and `git ls-files docs/` returns **0** against 150+ local files. This is
the constraint that made the spec's `docs/audits/trajectory/` undeliverable and moved this audit to
`artifacts/trajectory-v0/`. `non-goals.md` had already recorded the same contrast for M26-0 under the
heading *"Why `artifacts/` and not `docs/`"*, concluding: *"An audit that cannot be committed is not
an audit; it is a local note."* This audit's landing site follows that committed precedent;
**ADR 0062** records it as a decision.

## Answer to the Exit Gate

> *"File conflicts with v1.4 Adoption are clear."*

**Answered.** 55 files measured over six commits; 40 in the mainline's own territory, **15 shared**,
of which **3 are edited by this batch concurrently**. The single highest-risk file is
`packages/trust-index/src/index.ts` (the barrel), and the single hardest gate is
`tests/schema/schema-compatibility.test.ts`, which reds on any field added to a closed schema.

## What this chapter does not claim

- The six-commit window is a choice, not a measurement of the whole mainline. A longer window would
  show more files; six covers R-8 through M26-0, i.e. the currently active work.
- No claim that the 15 shared files *will* conflict. They are the surface where conflict is possible.
- The four stable schemas are labelled **inferred** throughout. If an upstream enumeration exists
  outside this repo, it was not read.
