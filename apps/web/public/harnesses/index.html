Agent Harnesses

CallLint provides deterministic static preflight inspection for agent hosts and development environments that can execute MCP servers and agent tools.

Supported Hosts

CallLint tracks 18 agent harnesses: 9 with native auto-discovery (--agent <id>), 1 scanned by explicit path (calllint scan <path>), 8 documented only, with no detection yet.

P0/P1/P2-P3 order these hosts by how commonly they are used, not by how well CallLint supports them. Each host below carries its own support label.

Native Support (P0)

  • Claude Code by Anthropic Auto-detects
    CallLint scans MCP server entries only. Skills, hooks and permission settings in the same file are not covered.
  • Claude Desktop by Anthropic Auto-detects
    CallLint scans MCP server entries only. Other Claude Desktop settings in the same file are not covered.
  • Cursor by Anysphere Auto-detects
    CallLint scans MCP server entries only. Cursor rules and editor settings are not covered.
  • WorkBuddy by Tencent Cloud Auto-detects
    CallLint scans MCP server entries only. Other WorkBuddy settings in the same file are not covered.

Official MCP Registry

CallLint is published to the Official MCP Registry as io.github.calllint/calllint (package: calllint-mcp).

Platforms that consume the Official MCP Registry can discover CallLint automatically.
