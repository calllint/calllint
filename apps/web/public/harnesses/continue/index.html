Continue

CallLint support for Continue by Continue. CallLint does not auto-discover Continue configuration. A block file may live in .continue/mcpServers as YAML or as JSON copied from another host, so a deterministic extractor must read both shapes before this page can promise more than where the config lives.

P2 Guide only

Usage

CallLint does not yet support native auto-discovery for Continue. No automatic detection yet — this page documents where the config lives.

Configuration Paths

CallLint looks for Continue configurations in:

  • <project>/.continue/mcpServers/*.yaml
  • <project>/.continue/mcpServers/*.json
  • config.yaml mcpServers block

Authority Surfaces

Continue can grant tools the following authority surfaces:

  • mcp
  • tools
  • vscode-extensions

Distribution

CallLint is available for Continue through:

  • mcp-stdio (via officialMcpRegistry) — Listing not yet verified

Support Status

Guide only — No automatic detection yet — this page documents where the config lives.

CallLint publishes no scan command for Continue yet. That is a statement about CallLint's coverage, not about Continue: see Coverage Boundary for what would have to be built first.
