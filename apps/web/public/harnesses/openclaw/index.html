OpenClaw

CallLint support for OpenClaw by Open Source. CallLint scans MCP configuration only. Skills and exec permissions are not covered.

P3 Auto-detects

Why scan OpenClaw?

OpenClaw combines MCP servers with skills and an exec surface in one config, so a server that can start a process sits beside skills that decide when to start one.

Usage

CallLint can auto-discover and scan OpenClaw configurations:

calllint scan --agent openclaw

How to start

Install nothing globally — run CallLint straight from npm:

npx calllint scan --auto

Then scan OpenClaw specifically:

calllint scan --agent openclaw

How to verify it worked

Treat any exec-capable server as REVIEW regardless of its verdict, then check what CallLint recorded as evidence — the exec surface is outside what a config scan can prove safe.

A No blockers observed verdict means exactly that — no blocker under the evidence CallLint could collect. It is not a guarantee, and Insufficient evidence never becomes it on its own. See Coverage Boundary for what this scan does not look at.

Configuration Paths

CallLint looks for OpenClaw configurations in:

  • ~/.openclaw/openclaw.json
