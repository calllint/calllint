Roo Code

CallLint support for Roo Code by Roo Code Inc. CallLint does not support Roo Code discovery. Its upstream repository is archived, so config evidence was not collected: recording a config path from a possibly-discontinued product would assert a state nobody has verified.

P3 Guide only
