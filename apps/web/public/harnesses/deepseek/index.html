DeepSeek Agent Harness Authority

The model can change. The permissions do not.

DeepSeek can be used through multiple agent harnesses. Replacing Claude with DeepSeek does not itself change the MCP servers, filesystem access, shell commands, API calls, or other authority the harness grants. CallLint inspects supported MCP and agent-tool configuration before execution.

What CallLint Does

  • Statically scans MCP and agent-tool configuration
  • Returns SAFE, REVIEW, BLOCK, or UNKNOWN with evidence
  • Identifies filesystem, shell, network, and API authority
  • Does not execute, install, or connect to servers
  • Works offline by default

What CallLint Does Not Do

  • Does not evaluate model safety or capabilities
  • Does not certify harnesses as "safe" or "secure"
  • Does not prove runtime behavior
  • Does not replace code review or security audit
  • UNKNOWN is not SAFE — it means the surface could not be verified statically
