DeepSeek Harness Authority

Claude Code + DeepSeek

Claude Code (Anthropic) can grant authority through mcp, filesystem, and shell. Using DeepSeek as the model does not change these permissions — the harness configuration controls what the agent can access.

Authority Surfaces

  • MCP servers: Model Context Protocol servers with filesystem, shell, network, and API capabilities
  • Filesystem: Direct filesystem read/write access
  • Shell: Shell command execution

Scan with CallLint

CallLint can automatically discover and scan Claude Code configuration:

npx calllint scan --agent claude-code

Or scan all detected agent configs:

npx calllint scan --auto

Expected config paths:

  • ~/.claude/settings.json
  • /.claude/settings.json

What Changes When Using DeepSeek?

The model identity changes. The authority surfaces do not. Claude Code grants the same filesystem, shell, network, and API permissions regardless of which model you select.

What CallLint Inspects

  • Filesystem access patterns (read, write, delete)
  • Shell command execution capabilities
  • Network endpoints (HTTP, WebSocket, SSE)
  • Environment variable access
  • Package install and supply-chain surfaces

CallLint does not:

  • Evaluate model safety or capabilities
  • Certify Claude Code as "safe" or "secure"
  • Execute or install the servers it inspects
  • Make recommendations based on popularity or model choice
UNKNOWN is not SAFE. It means the surface could not be verified statically. Review manually or use a published Trust Page.
