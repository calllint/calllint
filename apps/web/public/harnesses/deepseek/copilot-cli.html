DeepSeek Harness Authority

GitHub Copilot CLI + DeepSeek

GitHub Copilot CLI (GitHub) can grant authority through shell and cli. Using DeepSeek as the model does not change these permissions — the harness configuration controls what the agent can access.

Authority Surfaces

  • Shell: Shell command execution
  • CLI: Command-line interface tools

CallLint Coverage

CallLint does not yet auto-discover GitHub Copilot CLI configuration. You can still:

  • Look up published MCP servers on the Trust Index
  • Scan inline MCP configuration: npx calllint scan <config.json>
  • Review general MCP security guidance

Config mechanism: Config mechanism requires verification

Coverage boundary: CallLint does not yet auto-discover Copilot CLI configuration.

What Changes When Using DeepSeek?

The model identity changes. The authority surfaces do not. GitHub Copilot CLI grants the same filesystem, shell, network, and API permissions regardless of which model you select.

What CallLint Inspects

  • Filesystem access patterns (read, write, delete)
  • Shell command execution capabilities
  • Network endpoints (HTTP, WebSocket, SSE)
  • Environment variable access
  • Package install and supply-chain surfaces

CallLint does not:

  • Evaluate model safety or capabilities
  • Certify GitHub Copilot CLI as "safe" or "secure"
  • Execute or install the servers it inspects
  • Make recommendations based on popularity or model choice
UNKNOWN is not SAFE. It means the surface could not be verified statically. Review manually or use a published Trust Page.
