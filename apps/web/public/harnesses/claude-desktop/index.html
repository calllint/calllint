Claude Desktop

CallLint support for Claude Desktop by Anthropic. CallLint scans MCP server entries only. Other Claude Desktop settings in the same file are not covered.

P0 Auto-detects

Usage

CallLint can auto-discover and scan Claude Desktop configurations:

calllint scan --agent claude-desktop

Configuration Paths

CallLint looks for Claude Desktop configurations in:

  • ~/Library/Application Support/Claude/claude_desktop_config.json
  • %APPDATA%/Claude/claude_desktop_config.json

Authority Surfaces

Claude Desktop can grant tools the following authority surfaces:

  • mcp
  • filesystem

Distribution

CallLint is available for Claude Desktop through:

  • mcp-stdio (via officialMcpRegistry) — AVAILABLE
